## What I build

| | |
|---|---|
| **Telegram bots** | Command flows, inline keyboards, payments, admin panels, webhook-first deployments that stay up under load. |
| **Web** | Dashboards and landing surfaces for the products behind the bots — auth, billing, usage analytics. |
| **Apps** | Cross-platform mobile clients that talk to the same backend as the bots. |
| **AI skills** | Reusable agent skills and tool-calling workflows — prompt design, retrieval, structured output, guardrails. |

I care about the unglamorous parts: idempotent handlers, sane rate limits, logging you can actually debug from, and a bot that answers in under a second.
